Resume Screening AI ⭐⭐⭐⭐⭐

A smart AI-powered Resume Screening application that analyzes resumes and matches them against job descriptions. Upload a resume PDF and instantly get a resume score, extracted skills, and job match percentage.

🚀 Features

✅ Upload Resume in PDF Format

✅ Extract Skills Automatically

✅ Calculate Resume Score

✅ Compare Resume with Job Description

✅ Generate Job Match Percentage

✅ User-Friendly Streamlit Interface


📌 Project Overview

Recruiters often receive hundreds of resumes for a single job opening. Manually reviewing each resume is time-consuming and inefficient.

This project automates the initial screening process by:

Extracting text from uploaded resumes.
Identifying relevant technical skills.
Comparing the resume with the job description.
Calculating a match percentage.
Recommending the most suitable candidates.
