# ❤️ Heart Disease Prediction Web App

A Full Stack Machine Learning Web Application that predicts heart disease risk using patient health data.

## 🚀 Tech Stack

- Python
- Scikit-Learn
- FastAPI
- Streamlit
- Pandas
- NumPy

## 📌 Features

✅ Heart Disease Prediction  
✅ FastAPI Backend  
✅ Streamlit Frontend  
✅ Probability Score  
✅ ML Model Deployment  

## ⚡ Run Project

### Run Backend

uvicorn main:app --reload

### Run Frontend

streamlit run app.py
