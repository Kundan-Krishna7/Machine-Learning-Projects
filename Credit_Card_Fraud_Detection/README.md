# Credit Card Fraud Detection
Dataset used:
Credit Card Fraud Detection Dataset from Kaggle

Link:
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

This project uses Machine Learning to detect fraudulent credit card transactions using highly imbalanced transaction data.

## 📌 Features
- Data Cleaning & EDA
- Random Forest Classifier
- Hyperparameter Tuning
- PR-AUC Evaluation
- Confusion Matrix Heatmap
- Fraud Prediction System

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## 🚀 Model Prediction
- Fraud Transaction ❌💳
- Non-Fraud Transaction ✅💳
