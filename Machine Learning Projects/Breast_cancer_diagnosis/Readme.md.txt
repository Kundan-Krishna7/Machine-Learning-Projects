# Breast Cancer Diagnosis using Machine Learning

## Project Overview
This project predicts whether a breast tumor is Benign or Malignant using Machine Learning techniques.

The project was built using Python and Scikit-learn and includes complete data preprocessing, visualization, model training, hyperparameter tuning, and prediction system implementation.

---

## Objectives
- Analyze breast cancer diagnostic data
- Detect important feature relationships
- Build an accurate classification model
- Predict whether a tumor is Benign or Malignant

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## Machine Learning Workflow
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Heatmap Correlation Analysis
4. Outlier Detection using Boxplots
5. Train-Test Split
6. Feature Scaling using StandardScaler
7. PCA for Dimensionality Reduction
8. SVM Model Training
9. Hyperparameter Tuning using GridSearchCV
10. Model Evaluation using Confusion Matrix
